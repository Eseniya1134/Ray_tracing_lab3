# Лабораторная работа - "ТРАССИРОВКА ЛУЧЕЙ" 

Данный проект представляет собой интерактивный рендерер, реализующий базовую трассировку лучей в фрагментном шейдере GLSL с использованием C# и библиотеки OpenTK. В сцене поддерживается отображение примитивов (сферы, куб, тетраэдр) с эффектами освещения, отражений и частичной прозрачности.

## Назначение

Проект создан в рамках изучения темы "Трассировка лучей" по курсу "Компьютерная графика". Он позволяет визуализировать 3D-сцену с примитивами, управлять положением камеры, цветами объектов и степенью прозрачности сфер. Подходит для учебных демонстраций и экспериментов с алгоритмами рендеринга в реальном времени.

## Возможности
- Отображение сцены, содержащей:
  - Две сферы (с возможностью настройки прозрачности)
  - Куб (с настройкой цвета)
  - Тетраэдр (с настройкой цвета)
  - Окружающие стены (шесть цветных поверхностей)
    
- Интерфейс управления:
  - Настройка цветов куба и тетраэдра через трекбары
  - Настройка положения камеры по осям X, Y, Z
  - Настройка прозрачности сфер
    
- Эффекты:
  - Освещение по модели Фонга (ambient + diffuse + specular)
  - Отражения от зеркальных поверхностей
  - Мягкие тени от объектов
  - Множественные отражения (ограниченная глубина рекурсии)

## Используемые технологии
- C# (.NET Framework)
- OpenGL 4.3 (через OpenTK)
- GLSL (vertex и fragment shaders)
- WinForms для пользовательского интерфейса

## Структура проекта
- `raytracing.vert` — вершинный шейдер  
- `raytracing.frag` — фрагментный шейдер (реализует трассировку лучей)  
- `Form1.cs` — основное окно приложения, отрисовка и взаимодействие с шейдерами  
- `Program.cs` — точка входа в программу  
- `Shaders/` — папка с шейдерами

## Входные данные
- Файл шейдера `raytracing.frag` содержит жестко заданную сцену:
  - Геометрия сцены задается внутри кода шейдера
  - Параметры объектов (цвета, координаты, радиусы) передаются через uniform-переменные из C#

## Управление
- Трекбары управления:
  - **R/G/B (1–3)**: изменение цвета куба
  - **R/G/B (4–6)**: изменение цвета тетраэдра
    
- Камера:
  - **X/Y/Z (7–9)**: перемещение камеры
    
- Прозрачность:
  - **Сфера 1**: вертикальный скроллбар 1
  - **Сфера 2**: вертикальный скроллбар 2

## Сцена содержит:
- Шесть треугольных стен (задняя, передняя, левая, правая, потолок, пол)
- Зеркальные сферы
- Цветной куб
- Цветной тетраэдр
- Источник света, дающий мягкие тени

## Примечания
- Прозрачность регулируется в диапазоне от 0 (непрозрачная) до 1 (полностью прозрачная).
- Отражения реализованы с ограниченной глубиной (по умолчанию — 8).
- Все материалы определены в `initializeDefaultLightMaterials()`.
